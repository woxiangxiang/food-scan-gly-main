# 食物升糖指数识别 H5 应用需求文档

> 版本 v1.0   |   发布日期 2025‑05‑14   |   作者 ChatGPT‑o3

---

## 1 项目背景

* **目标人群** : 2 型糖尿病患者及需要关注血糖波动的用户。
* **核心痛点** : 外食或就餐前无法快速判断食物的升糖指数（GI）与对血糖的影响；传统记录血糖方式繁琐，不直观。
* **解决方案** : 提供一个可随时拍照/上传食品图片并自动返回 GI 及饮食建议的轻量级 H5 应用，并在本地跟踪血糖历史。

## 2 目标与衡量指标

| 目标        | 关键指标 (KPI)                    |
| --------- | ----------------------------- |
| 快速识别食物 GI | 识别耗时 ≤ 5 s，Top‑1 准确率 ≥ 80%    |
| 降低手动记录成本  | 进入 "我的" 页面后 1 s 内显示最近 3 天血糖曲线 |
| 保证离线可用性   | 主要功能（浏览食物、查看历史血糖）在离线模式下可正常运行  |

## 3 用户角色与核心场景

| 角色      | 主要动机             | 核心场景                  |
| ------- | ---------------- | --------------------- |
| 患者 / 家属 | 快速确认食物是否适合当前血糖情况 | 餐前对着菜品拍照，一键获取 GI + 建议 |
| 营养师     | 教育/辅导患者          | 演示不同食物 GI，帮助制定食谱      |

│───────────────────────────────────│

### 4.1 底部 Tab

* **识别** (default)
* **食物**
* **我的**

### 4.2 识别页

| 区块      | 说明                                   |
| ------- | ------------------------------------ |
| 拍照/相册按钮 | 调用摄像头或系统文件选择器；按钮置灰时显示加载动画            |
| 识别结果卡片  | 显示食物名 / 估算 GI 值 / 分类标签（低、中、高） / 建议文本 |

### 4.3 食物页

| 区块     | 说明                                   |
| ------ | ------------------------------------ |
| 筛选条    | Filter Chips：全部 / 低 GI / 中 GI / 高 GI |
| 食物卡片网格 | 单元包含图片、名称、GI 数值、简短描述；2 列瀑布流布局        |

### 4.4 我的页

| 区块     | 说明                                 |
| ------ | ---------------------------------- |
| 血糖折线图  | 绘制最近 30 条记录；x 轴日期，y 轴血糖值           |
| 统计卡片   | 平均值 / 最低值 / 最高值（最近 72 h）           |
| 记录血糖按钮 | 呼出底部滑层，输入血糖值 & 时间，保存到 localStorage |
| 历史记录列表 | 倒序列表，支持滑动删除                        |

## 5 交互流程概述

1. **拍照识别**
      a. 点击拍照 → 调用 `getUserMedia`
      b. 拍照成功即上传至通义千问 VL API
      c. 返回 JSON `{"food":"米饭","gi":82,"suggestion":"建议控制主食量..."}`
      d. 渲染结果卡片，同时缓存至 `sessionStorage.lastResult`
2. **血糖记录**
      a. 点击「记录血糖」→ 打开滑层表单
      b. 输入数值确认 → 写入 `localStorage.bloodGlucoseRecords[]`
      c. 发布 `storage` 事件，折线图自动刷新

## 6 功能需求明细

### 6.1 识别页

| 编号   | 需求                                | 优先级    |
| ---- | --------------------------------- | ------ |
| R‑1  | 支持拍照或从相册选择单张图片                    | High   |
| R‑2  | 调用通义千问 VL 模型 API 进行图片→GI 识别       | High   |
| R‑3  | 展示识别置信度 < 0.6 时给出「结果不确定，建议手动确认」提示 | Medium |
| R‑4  | 识别结果可分享（系统分享 / 复制链接）              | Low    |

### 6.2 食物页

| 编号   | 需求                                     | 优先级    |
| ---- | -------------------------------------- | ------ |
| F‑1  | 初始化时从 `/static/foods.json` 读取 30 条食物数据 | High   |
| F‑2  | 前端本地筛选；Chip 点击高亮状态                     | High   |
| F‑3  | 食物卡片点击进入「食物详情弹窗」显示更多营养信息               | Medium |

### 6.3 我的页

| 编号   | 需求                                 | 优先级  |
| ---- | ---------------------------------- | ---- |
| M‑1  | 折线图使用 `chart.js` 简约主题              | High |
| M‑2  | 「记录血糖」表单 : 输入范围 1‑30 mmol/L，默认当前时间 | High |
| M‑3  | 本地数据结构                             |      |

## 7 数据与接口

### 7.1 通义千问 VL 识别接口

* **Endpoint** : `POST https://dashscope.aliyuncs.com/api/v1/images:annotate`
* **请求体**

```json
{
  "model": "qwen-vl-plus",
  "prompt": "Identify the food and return its glycemic index.",
  "image_url": "<uploaded_url>"
}
```

* **重点字段** : `food`, `gi`, `suggestion`, `confidence`

### 7.2 静态数据 `foods.json`

```json
[
  {
    "name": "糙米饭",
    "gi": 55,
    "description": "糙米保留麸皮, 纤维含量高, GI 较低",
    "image": "https://images.unsplash.com/..."
  }
]
```

## 8 技术栈与架构

| 层     | 技术                                         |
| ----- | ------------------------------------------ |
| 前端    | **Next.js 14 App Router** + **TypeScript** |
| UI    | **TailwindCSS** + **shadcn/ui** 组件库        |
| 数据可视化 | echarts （折线图）                              |
| 模型接入  | 阿里云 **通义千问 VL Plus**                       |
| 本地存储  | `localStorage`（血糖） / 静态 JSON（食物列表）         |

## 9 非功能需求

* **性能** : 首屏 < 1.5 s (Fast 3G)；图片懒加载 + Tailwind JIT
* **PWA** : Service Worker 缓存静态资源 & 脱机友好降级
* **安全** : 不存储用户隐秘数据；HTTPS 强制；API Key 存于服务端代理
* **可访问性** : 所有按钮满足 WCAG 2.1 AA 对比度，支持 `prefers-reduced-motion`
* **i18n** : 预留多语言切换（中 / 英）

## 10 错误处理 & 边界情况

| 场景                | 处理                                                   |
| ----------------- | ---------------------------------------------------- |
| 模型识别失败 / 超时       | toast: "网络异常，请稍后重试"，并允许重传                            |
| localStorage 写入失败 | fallback 至 Memory & 提示 "浏览器隐私模式可能受限"                 |
| 无网络               | 识别按钮置灰；食物 / 我的页面可正常浏览 & 编辑（写入 IndexedDB 离线队列，回网自动同步） |
